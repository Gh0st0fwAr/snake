# Snake

Классическая змейка на **Vue 3**, **TypeScript** и **Vite** — с темами оформления, адаптивным полем и сохранением выбранного стиля.

**Играть онлайн:** [gh0st0fwar.github.io/Snake](https://gh0st0fwar.github.io/Snake/)

---

## Управление, правила и интерфейс

### Как начать

1. Откройте игру по ссылке выше или запустите локально (`npm run dev`).
2. Нажмите **«Начать игру»** на стартовом экране.
3. Управляйте змейкой стрелками на клавиатуре.

### Управление

| Клавиша | Действие |
| --- | --- |
| `←` | Поворот / движение влево |
| `→` | Поворот / движение вправо |
| `↑` | Поворот / движение вверх |
| `↓` | Поворот / движение вниз |

Управление работает только во время активной игры. Разворот на 180° заблокирован.

### Правила

- Змейка двигается автоматически с интервалом **0,7 секунды**.
- На поле появляется **яблоко**; при столкновении с ним змейка **растёт**.
- При выходе за край поля змейка **появляется с противоположной стороны**.
- Столкновение головы с хвостом — **Game Over**.
- После проигрыша нажмите **«Рестарт»**, чтобы очистить поле и вернуться к стартовому экрану.

### Интерфейс

| Элемент | Описание |
| --- | --- |
| **Игровое поле** | Квадратная сетка (по умолчанию 16×16). Размер клеток подстраивается под высоту окна с отступами **30 px** сверху и снизу. |
| **Стартовый экран** | Полупрозрачный оверлей и кнопка «Начать игру». |
| **Game Over** | Заголовок и кнопка «Рестарт». |
| **Панель «Стиль»** | Переключение между пятью темами оформления справа от поля. |

### Темы оформления

| Тема | Описание |
| --- | --- |
| **Arcade** | Тёмный неон, свечение клеток |
| **Paper** | Светлая «тетрадь» с линовкой и чернилами |
| **Pixel** | 8-bit: без скруглений, толстая рамка, «кирпичики» |
| **Candy** | Пастель, круглые «конфетки», мягкие тени |
| **Noir** | Жёсткий чёрно-белый «киношный» кадр |

Выбранная тема сохраняется в `localStorage` и остаётся активной после перезагрузки страницы (**F5**).

## Документация по коду

### Стек

- **Vue 3** — UI, оверлеи и переключатель тем
- **TypeScript** — игровая логика
- **Vite** — сборка и dev-сервер
- **SCSS** — стили (BEM, CSS-переменные для тем)
- **@fontsource** — шрифты Syne и Lexend

### Структура проекта

```
src/
├── Main.vue                 # UI: оверлеи, темы, связь с Grid
├── main.js                  # Точка входа, шрифты и стили
├── composables/
│   └── useLocalStorage.ts   # Сохранение темы в localStorage
├── constants/
│   └── themes.ts            # Список тем и валидация ThemeId
├── scss/
│   ├── main.scss            # Глобальные стили
│   ├── variables.scss       # SCSS-переменные (отступы, шрифты)
│   ├── game.scss            # BEM-блок .game и компоненты интерфейса
│   └── themes.scss          # CSS-переменные и отличия тем
└── ts/
    ├── grid.ts              # Поле, цикл движения, яблоко, game over
    ├── snake.ts             # Голова/сегменты, управление, направление
    └── gridCell.ts          # Клетка: классы --snake / --apple
```

### Архитектура

**`Grid`** — центральный класс. Создаёт DOM-поле, хранит `cellMap`, управляет таймером движения и обработкой столкновений. Принимает enum **`Size`** (`Small` 16×16, `Medium` 22×22, `Large` 28×28) и колбэк `onGameOver`.

**`Snake`** — сегмент змейки (голова или хвост). Голова слушает клавиатуру и меняет `direction`; движение выполняет `Grid.move`.

**`Cell`** — одна клетка сетки. Состояние задаётся классами BEM:

- `game__cell--snake` — сегмент змейки
- `game__cell--apple` — яблоко

Цвета не зашиты в TypeScript — они приходят из CSS-переменных активной темы.

### Игровой цикл

```
startGame()
  → isRunning = true
  → setInterval(move, 700 ms)

каждый тик:
  вычислить новую клетку по direction
  (при выходе за край — wrap)
  если клетка занята хвостом → gameOver()
  иначе сдвинуть хвост, переместить голову
  если на клетке яблоко → вырастить хвост, makeApple()
  render()
```

### Размеры поля

Перечисление `Size` в `grid.ts`:

| Размер | Сетка |
| --- | --- |
| `Small` | 16 × 16 *(используется в Main.vue)* |
| `Medium` | 22 × 22 |
| `Large` | 28 × 28 |

Высота клетки вычисляется из `window.innerHeight` с учётом вертикальных отступов (30 px сверху и снизу).
