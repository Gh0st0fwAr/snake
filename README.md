# Классическая змейка на TypeScript 🐍

Минималистичная реализация легендарной аркадной игры «Змейка», написанная на чистом **TypeScript** с использованием HTML5 Canvas. Проект демонстрирует применение объектно-ориентированного подхода (ООП), типизации и базовых паттернов разработки игр на веб-платформе.

## Стек технологий
* **Язык:** TypeScript
* **Рендеринг:** HTML5 Canvas API (2D контекст)
* **Сборка и деплой:** GitHub Pages

---

## 🎮 Игровой процесс (Gameplay)

Игрок управляет ползающей змейкой, которая перемещается по сетке игрового поля.
1. **Цель игры:** Набрать максимально возможное количество очков, поедая появляющуюся на поле еду (яблоки).
2. **Рост змейки:** Каждое съеденное яблоко увеличивает длину тела змейки на один сегмент и добавляет очки к общему счету.
3. **Условия проигрыша (Game Over):** Игра завершается, если голова змейки врезается в границы игрового поля или в собственное тело.

### Управление
Перемещение осуществляется с помощью клавиш со стрелками на клавиатуре:
* `ArrowUp` — движение вверх
* `ArrowDown` — движение вниз
* `ArrowLeft` — движение влево
* `ArrowRight` — движение вправо

> 💡 **Особенность:** В игре реализована защита от «самосъедения» при резком развороте — змейка не может мгновенно пойти в противоположную сторону (например, влево, если в данный момент она движется вправо).

## 🏗 Архитектура и структура кода

Код разделен на логические классы, каждый из которых отвечает за свою изолированную часть игровой системы:

### 1. `Snake` (Класс Змейки)
Управляет состоянием и поведением главного персонажа.
* Хранит массив координат всех сегментов тела.
* Отвечает за логику движения (`move`), изменение направления (`changeDirection`) и увеличение длины при обработке съеденной пищи.

### 2. `Food` (Класс Еды)
Отвечает за генерацию и отрисовку объектов пищи.
* Хранит текущую координату `(x, y)` яблока на поле.
* Содержит метод случайного спавна (`randomize`), который рассчитывает новые координаты в пределах игровой сетки так, чтобы еда не появлялась прямо на теле змейки.

### 3. `Game` / `Engine` (Игровой движок)
Центральный управляющий класс, связывающий компоненты воедино.
* Инициализирует HTML5 Canvas и запускает игровой цикл через `setInterval` или `requestAnimationFrame`.
* Обрабатывает события клавиатуры (`addEventListener('keydown')`).
* На каждой итерации цикла выполняет три главных шага:
  1. **Update:** Обновление координат змейки.
  2. **Check Collision:** Проверка столкновений (с едой, стенами или хвостом).
  3. **Render:** Полная перерисовка холста (очистка экрана, отрисовка еды, отрисовка змейки и вывод текущего счета).

## 🛠 Локальный запуск и разработка

Чтобы развернуть и запустить проект у себя на компьютере, выполните следующие шаги:

1. **Клонируйте репозиторий:**
   ```bash
   git clone git@github.com:Gh0st0fwAr/snake.git
   cd snake
Установите зависимости:

Bash
npm install
# или если используется yarn
yarn install
Запустите сервер для разработки:

Bash
npm run dev
# или
yarn dev
После этого откройте локальный адрес (обычно http://localhost:3000 или указанный в терминале порт) в браузере.

Сборка проекта (Production):

Bash
npm run build
# или
yarn build
