# Классическая змейка на TypeScript 🐍

Данная документация описывает классическую игру «Змейка», реализованную на базе веб-технологий с использованием сеточной модели позиционирования элементов. Проект разработан без применения графического контекста отрисовки (Canvas), полностью полагаясь на возможности структурирования элементов через CSS Grid.

---

## 1. Архитектура и структура проекта

Проект представляет собой клиентское веб-приложение (Single Page Application), структура которого состоит из стандартного набора файлов:

*   **`index.html`** — декларативное описание структуры интерфейса, разметка игрового экрана, табло счета и модальных окон.
*   **`style.css`** — визуальное оформление интерфейса, стили элементов управления и, главное, конфигурация игрового поля на базе двухмерных сеток (CSS Grid).
*   **`script.js`** (или аналогичный скрипт управления) — программная логика игры, обработка пользовательского ввода, игровой цикл, механика перемещения змейки и генерация игровых объектов.

---

## 2. Технологический стек и особенности реализации

*   **HTML5:** Семантическая разметка для каркаса приложения.
*   **CSS3 (Grid Layout):** Ключевой компонент визуализации. Вместо динамической отрисовки пикселей на холсте, игровое поле представляет собой жестко заданную сетку из строк и колонок (`display: grid`). Каждый сегмент змейки и элемент еды позиционируются внутри этой сетки путем динамического изменения их координат (номеров строк и колонок в стилях).
*   **Vanilla JavaScript (ES6+):** Реализация логики без внешних фреймворков и библиотек.

---

## 3. Механика и логика игры

### 3.1. Игровое поле (CSS Grid)
Поле разбито на координатную сетку фиксированного размера (например, 20x20 или 40x40 ячеек). В CSS это задается свойствами:
```css
.game-board {
    display: grid;
    grid-template-rows: repeat(20, 1fr);
    grid-template-columns: repeat(20, 1fr);
}

Каждая ячейка сетки имеет уникальные координаты (x, y).

3.2. Состояние и движение змейки
Змейка инициализируется как массив объектов, где каждый объект хранит координаты сегмента:

JavaScript
let snake = [
    { x: 10, y: 10 },
    { x: 10, y: 11 },
    { x: 10, y: 12 }
];
Игровой цикл: Запускается с помощью функции setInterval или requestAnimationFrame. На каждом такте (шаге) игры вычисляются новые координаты головы змейки на основе текущего направления движения.

Перемещение: Новый элемент (голова) добавляется в начало массива змейки, а последний элемент (хвост) удаляется, создавая иллюзию движения. Если змейка съедает еду, хвост не удаляется, и длина тела увеличивается.

Рендеринг: Для каждого сегмента массива JavaScript динамически создает DOM-элемент и задает ему свойства:

JavaScript
segmentElement.style.gridRowStart = segment.y;
segmentElement.style.gridColumnStart = segment.x;

### 3.3. Генерация еды
Еда появляется в случайной ячейке игрового поля. При генерации координат проверяется условие, чтобы еда не оказалась на ячейке, которую в данный момент занимает тело змейки. При совпадении координат головы змейки и еды:
1. Игроку начисляются очки.
2. Еда удаляется с поля и генерируется в новом месте.
3. Длина змейки увеличивается.

### 3.4. Условия завершения игры (Game Over)
Проверка коллизий выполняется на каждом шаге игрового цикла. Игра завершается в следующих случаях:
*   **Столкновение с границами:** Координаты головы змейки выходят за рамки установленного размера сетки (меньше 1 или больше максимального значения сетки).
*   **Самопересечение:** Координаты головы змейки совпадают с координатами любого из элементов ее тела.

---

## 4. Управление и интерфейс

Управление игровым процессом осуществляется с клавиатуры с помощью обработчика событий `keydown`. 

### Клавиши управления:
*   `ArrowUp` / `W` — движение вверх
*   `ArrowDown` / `S` — движение вниз
*   `ArrowLeft` / `A` — движение влево
*   `ArrowRight` / `D` — движение вправо

*Примечание: В системе управления реализована блокировка разворота на 180 градусов. Если змейка движется вправо, нажатие клавиши «влево» игнорируется для предотвращения моментального самопересечения.*

---

## 5. Настройка и кастомизация проекта

Вы можете изменять параметры игры непосредственно в коде:
1.  **Скорость игры:** Изменяется путем корректировки интервала таймера игрового цикла в миллисекундах (меньше интервал — выше скорость).
2.  **Размер поля:** Корректируется одновременно в CSS (`grid-template-...`) и в JavaScript переменных, отвечающих за ограничения координат сетки.
3.  **Стилизация ячеек:** Внешний вид змейки и еды меняется через CSS-классы (например, добавление скруглений углов `border-radius`, градиентов или анимаций для элементов сетки).

---

## 6. Запуск проекта

1. Склонируйте репозиторий или скачайте исходные файлы проекта.
2. Откройте файл `index.html` в любом современном веб-браузере.
3. Для старта игры используйте элементы управления на экране или нажмите клавиши направления движения.
